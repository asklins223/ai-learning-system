# Restored Live2D candidate PSD

`seethrough-restored-candidate-live2d-v2.psd` 是基于 See-Through PSD 和恢复候选层重新组装的 RGBA PSD。

- 画布：1024×1024
- 活动图层：25 个
- 透明模式：RGBA
- 法杖：`objects-restored-candidate`
- 尾巴：`tail-restored-candidate`
- 去尾衣服：`topwear-tail-masked-candidate`

导入 Cubism 后，先检查法杖握持遮挡、尾根连接、衣服边缘和头发遮挡，再创建 ArtMesh 与参数。该文件仍是候选源文件，不包含 `.cmo3`、模型参数、物理文件或运行时注册信息。
