```bash
node --experimental-test-coverage --import tsx --test src/*.test.ts
node --experimental-test-coverage --import tsx --test src/__tests__/*.test.ts
node --experimental-test-coverage --import tsx --test lib/__tests__/*.test.ts

  src/handlers/parse-source.test.ts src/lib/worker-reliability.test.ts \

```

Node 20 的原生 runner 不支持 `--test-coverage-exclude`；上述试验性 loaded-file 口径包含被加载的测试文件，只统计测试实际加载的文件，不等于全仓或 production-source coverage。它仅作为 M0 缺口证据：正式门禁必须在 Node 22 加入测试文件排除、目录发现、全仓/关键模块/changed-lines 口径；API 61.28% 与 Worker 60.07% 均不能证明达到计划 70% 全仓门槛。
