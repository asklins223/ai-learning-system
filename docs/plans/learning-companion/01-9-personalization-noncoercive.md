## 2. 本轮上下文（§11.1）

用户在本轮可**快速表达**的约束：

- **时长**：3 / 10 / 20 分钟，或**自定义**；
- **本轮精力**：低负荷 / 正常；
- **挑战偏好**：温和 / 标准 / 挑战；
- **输入方式**：静音 / 可语音 / 只用触控或键盘；
- **复习范围**：聚焦一个星域 / 混合复习（按需出现）。

**默认行为与边界**：

- **默认只要求选择目的地**，其余为**可选约束**；
- **本轮精力不长期保存**、**不形成心理画像**；
- 这些值只影响 **route composition、表达、数量和互动选择**；
- 这些值**不能直接进入 mastery 或 official scheduler**。

## 3. 长期可编辑偏好（§11.2）

**可编辑偏好范围**：

- **默认输入优先级**（语音 / 触控结构操作 / 文字）；
- **明确禁用或不喜欢的 Encounter**；
- **反馈风格**（简洁 / 直接 / 引导式）；
- **伴星存在感**（安静 / 适度陪伴 / 主动建议）；
- **静音 / 专注与可见性**：页面级静音 / 专注、账号级角色动画 / 语音输出与全局关闭、**仅本设备持久化**的临时隐藏；
- **「不再提示」的 bounded suggestion classes**（有界建议类别）；
- **挑战倾向**和**单主题 / 交错复习偏好**；
- **默认时长、每周负荷、可用时间窗和通知边界**；
- **TTS 语速、字幕、音效、reduced-motion 和无障碍偏好**；
- **原始音频保留与隐私选择**。

**设置与帮助中心提供**：

- 「**重新播放首次引导**」；
- 「**伴星当前可使用哪些页面上下文**」。

**产品状态与学习偏好的边界**：

- onboarding **完成 / 跳过**属于**产品状态**，**不是学习偏好**；
- **重置偏好不得重新触发已跳过引导**。

**偏好管理能力**：所有偏好可**查看、修改、重置、导出和删除**。

**Agent 行为边界**：Agent **只能提出 `suggested preference`**，**不能静默改变**任何偏好。

## 4. 游戏感来源（§11.3）

**允许（游戏感应来自）**：

- 允许**选择目的地和路线**；
- 能**预测决定后果**；
- 通过操作看到**系统 / 因果 / 条件变化**；
- **修复错误光路**或**让星重新清晰**；
- **可信理解变化在知识世界显现**；
- **主动保存的问题得到回答 / 转化 / 安静归档**（Should）；
- **回看理解变化**（practice 航迹**默认不作长期显著资产**）。

**禁止（禁止清单）**：

- XP / 等级 / 金币 / 连击 / 宝箱；
- streak / 断签宽限 /「保住火焰」；
- 每日清空 / 自动追加 / 无限下一题；
- 排行榜 / 分享成绩 / 跨用户比较；
- 失败扣分 / 掉级羞辱 / 倒计时；
- 随机奖励 / 内容锁 / 体力墙；
- 让伴星通过**失望 / 焦虑 / 拟人依赖**催促学习。

## 5. 反馈文案规则（§11.4）

**要求**：使用**具体、可行动、非身份化**的表达。

**示例文案**：

> 「这次你已经能重建前三个步骤，边界条件还没独立验证。」

**禁止出现的文案**：

- 「你落后了」；
- 「欠了 N 项」；
- 「连续记录即将中断」；
- 「你已经完全掌握 92%」；
- 「再来一题保住进度」；
- 「你不适合这种学习方式」。
