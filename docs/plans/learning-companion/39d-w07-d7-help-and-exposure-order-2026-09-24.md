## 2. 决定一：以回答锁定的先后为界（**不是**评分返回时间）

39 §14.1.1 原文加粗：**"以回答锁定的先后为界，而非评分返回时间。"**

| 时刻关系 | 结论 |
| --- | --- |
| 帮助在**本次原回答锁定之前**已呈现 | **影响该份回答的条件** |
| 正常提交成功后**才**显示的答案、反馈或下一题讲解 | **不追溯降低**该份已锁定回答的独立性 |
| 帮助在锁定**前**已请求且**可能已呈现**、但回执**迟到** | **保留待核对并对账** |
| 一直无法对账 | 记 **「帮助条件无法确认」** 终态（§5） |

**四条实现约束**：

1. **顺序取自服务端记录**（提交时点 + 呈现回执），**不能只凭较晚到达的客户端时间**判它发生在提交后——39 §14.1.1 明写了这条反例。
2. **资格只能收紧（单调）**：后续求助、揭示或依据失效**可以收紧**资格；**不能**看到答案后改题意或放宽条件以迁就结果（39 §4.3 末段；D3 §5 已钉）。
3. **提交未确认时**可以保留草稿并请求揭示，但必须**说明"原回答状态未知"**，并按帮助条件处理，**不能声称已经独立提交成功**（39 §14.1.1）。
4. **补答、新题和下一次回忆重新计算各自的帮助范围**（39 §14.1.1）。

## 3. 决定二：跨入口共用一条帮助记录

**一个任务 ↔ 一条帮助记录**，内容四件：**目标修订、任务、产物、呈现回执**（39 §15.3-12 原话）。

**入口全列**：提示按钮 / 伴星 / 卡背 / 图示 / 语音 / TTS。

| 情形 | 结论 | 出处 |
| --- | --- | --- |
| 帮助已呈现后**切换入口** | 跨页面关联，**切到星图或卡片页洗不掉** | 39 §14.1.1、§16.21 |
| 文字已呈现但**语音失败** | 帮助**已呈现**，语音失败不消掉它，也不导致重复记账 | 39 §16.30 |
| **全部未送达** | **不凭"生成成功"认定已帮助** | 39 §16.30 |
| 呈现状态**未知** | **不签发独立证据**；不永久显示处理中 | 39 §14.1.1 末段 |
| **重复播放** | 不增加一次学习表现 | 39 §12.2.2 |
| 普通鼓励、重复题面 | **不自动算答案暴露** | 39b §5 的裁定记录 |
| 判定是否泄题 | **不用"答案原文是回复的子串"**——改述、图示和语音同样可能给出帮助 | 39b §5、§9.5 |

**一条推论**：既然"生成"与"呈现"是两件事（39 §12.2.2："内容生成、交给模型阅读与实际向用户呈现分别处理"），那么**读取材料给模型 ≠ 用户看到答案**。这条同样约束伴星的正文阅读。

## 4. 决定三：跨目标也要查（不能只看 ID 是否相同）

39 §14.1.1：**"不同目标也可能共享答案线索。先做条件提取、看卡背，再做应用题时，须检查前一步是否已提供后题的关键推理；仅换题名、数值或目标 ID 不会获得独立资格。"**

| 场景 | 处理 |
| --- | --- |
| 前一步（如 T1 卡背）已提供后题（如 T2 应用题）的关键推理 | 后题记为**带近期帮助**，**不记独立迁移** |
| 需要同时观察独立表现 | **在不揭示反馈的情况下先锁定相关回答**，或**把后题放到另一次条件清楚的回访**（39a 第六天演练的两个选项） |
| 用户随时求助 | **不为保住资格拒绝解释**（39 §14.1.1 末句） |

**实现约束**：跨目标判定**不能**只比 `taskId` 或 `objectiveId`。39c §7.2 也写了同一条（"不能只按 taskId 或 objectiveId 是否相同判断"）。判据是**内容线索的重叠**（§6 的集合关系）。

## 5. 决定四：终态「帮助条件无法确认」

| 要求 | 落地 |
| --- | --- |
| 保留回答 | 回答照常保存，不因条件未知而丢弃 |
| **不签发独立证据** | 不产生"独立正确"类结论 |
| **不让用户永久等待** | 明确结束本轮；**不永久显示处理中**（39 §16.37） |
| 允许未来一次条件清楚的新尝试 | 新任务重新计算帮助范围（§2 第 4 条） |
| 不做的事 | 不靠**用户自报"我没看过"**自动补签（39 §14.1.1 原话） |

**注意与"取消评估"的区别**：条件未知是"没对账上"，取消评估是"用户明确不要这条判定"（§7）。前者保留未来可能，后者到此为止。

## 6. 决定五：伴星作为暴露源（39b §9.7，原文接收为合同）

**性质**：答案暴露在本项目里**是已经存在、已经有表**的事实类别，缺的只有她这一头没往里写。

| 项 | 设计 |
| --- | --- |
| **写入门在服务端，不在她嘴里** | 她**不需要**一个"我泄露了"的工具——那会让她自己决定要不要记账 |
| **判据** | **集合关系**：她这句话有多少 ⊆ 本题题面／已揭示内容（即 G6 逐字比对能力的**反向用法**） |
| **触发** | 取现成的 `interactionState === "formal_answer"` |
| **目标身份** | `objective_id` / `objective_revision` 取**这一题冻结的那一版** |
| **`exposure_kind` 分档** | 只给到线索 → `evidence_reveal`；给出本题答案本体 → `answer_reveal`。**两档的信任后果已经在库里，不发明新语义** |
| **幂等** | 用现成的 `lex_v2_idem_unique (workspace_id, user_id, idempotency_key)` —— **重试／重发不许记成两次暴露，别另建去重** |
| **零 schema 变更** | 表列齐全（`card_id` 可空），不需要新列 |
| **RLS 陷阱** | 该表策略对 `ailearn_worker` 形同不存在 ⇒ **集测必须钉"换 user 写不进也读不到"** |
| **她读不到这条记账** | `<this_turn_facts>` **不含 exposure 行**——它是证据元数据，不是可播报的事实。**不许她因为"反正要记账"而开始用暴露解释用户的表现** |

**副产品**：39b §9.10 的那句话在这里变成可检验的差——"在作答页问她一句这道题的条件，然后回主页面把题答完"：做之前是"一次干净的独立作答"，做之后是"一行 `answer_reveal`"。

## 7. 决定六：三个独立命令（不许合成一个"结束"）

39 §5.5 末段、§16.36：

| 命令 | 行为 |
| --- | --- |
| **结束活动**（先到这里） | 默认**允许已受理回答的评估完成**；停止聊天/朗读不取消它 |
| **停止本次评估** | 保存原回答；**停止该任务后续尝试**；迟到报告**不作为有效判定或调度依据**；当次显示"回答已保存，评估已取消" |
| **撤销未来复习授权**（停订） | **不删除**已保留的学习观察 |

三条附加规则：

- **已先完成提交的判定不因后到取消而消失**，显示实际回执（39 §16.36："取消晚于成功提交时如实显示已完成，不能抹掉回执"）。
- **改变提醒或停订不影响保留有权查看的学习观察**（39 §5.5）。
- 生成额外解释、记忆提取、鼓励和星图投影失败**都不阻塞已经正确完成的回答保存或业务结算**（39c §7.4）。

## 8. 决定七：不新建平行事实类别

39 §15.3-19 原话："**不新建平行事实类别**。"

**三个检查点**（实施时逐条 grep 可验）：

1. 伴星暴露**复用 `learning_exposures_v2`**，不新增"帮助表"。
2. 呈现回执**复用 `learning_task_presentation_history`**（以及 `companion_stream_events` 里已有的进度事件），不新增第二套呈现记录。
3. `exposure_kind` **不新增取值**：`evidence_reveal` / `answer_reveal` 已经够表达"线索 vs 答案本体"这两档。

**同源要求**（39b §9.8）：求助后果 `assistance_consequence` span 的 `askable` **恒为真**、与 `formal-assessment-guard.ts` 的 `exposureLowersTrust` **同源**，**不许两处手写**。这条是"一个语义两处实现迟早分叉"的一个具体实例。

## 9. 验收判据（实施时逐条可跑）

| # | 判据 | 怎么算过 |
| --- | --- | --- |
| 1 | 提交前帮助 → 借助完成 | 在作答页问一句条件 → 回主页面作答 → 该份回答记为**借助**；该表多一行且 `exposure_kind` 判对 |
| 2 | 提交后揭示 → 不追溯降级 | 独立完成并成功提交，随后看卡背 → 断言**原回答不被降级** |
| 3 | 重发不产生第二行 | 同一幂等键重发 → 断言**只有一行**（撞 `lex_v2_idem_unique`） |
| 4 | 呈现未知 → 条件未知终态 | 构造呈现回执丢失 → 断言结束为「帮助条件无法确认」，**不签发独立证据、不永久处理中** |
| 5 | 跨入口不被洗掉 | 提示按钮给帮助后切到卡片页回答同一内容 → 断言帮助**跨入口生效** |
| 6 | 语音失败不消掉帮助 | 文字已呈现、语音失败 → 断言帮助**仍在**，且不重复记账 |
| 7 | 跨目标线索重叠 | T1 卡背后做 T2 应用题 → 断言 T2 记为**带近期帮助**，不记独立迁移 |
| 8 | 重复播放不计数 | 同一段讲解重播两次 → 断言学习表现**只记一次** |
| 9 | 三命令互不代替 | 分别执行三个命令 → 断言三条独立回执，且各自效果互不越界 |
| 10 | 换 user 读不到 | 换 user 的 preflight 也查不到那条 exposure（39b §14 的规矩） |
| 11 | 伴星读不到记账 | `<this_turn_facts>` 的键集里**不含** exposure 相关键 |
| 12 | 反向：非作答页零写入 | 普通闲聊轮、非作答页轮 → 该表**写入必须为 0** |
| 13 | 没有第二套事实类别 | grep 断言不存在第二张"帮助/exposure"表与第二套 kind 枚举 |
