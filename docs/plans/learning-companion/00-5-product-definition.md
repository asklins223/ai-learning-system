## 交付物

## 四个产品对象

用户只需理解四个对象：

| 产品对象 | 用户心智 | 系统职责 |
| --- | --- | --- |
| 理解星图 | 我的知识世界现在是什么样 | 展示共享知识和个人理解，选择目的地 |
| 伴星导航员 | 从进入系统起就能找到、和我一起走的学习伙伴 | 提供首次引导和页面帮助；进入学习目标后呈现路线、场景、语音和可选动作 |
| 学习航程 | 我这次想弄清的一小段内容 | 有目标、有预算、有终点的 Learning Session |
| 共学工作台 | 我真正动手或开口的地方 | 承载说、排、连、修、演等 Encounter |

## 统一核心循环

选目标 → 沿用显式偏好（可选补充时间/输入限制）→ Supervisor 默认只提议一条路线并提供"换一个" → 伴星把路线呈现为语音与可操作场景 → 用户通过说/排/连/修/演产生 Response Artifact → 独立 Critic 按冻结 rubric 与证据逐项评估 → 确定性内核写理解事件并运行 official scheduler → 来源页面就地展示真实变化，可选"在星图中查看" → 明确结束，是否继续由用户主动决定。

## 十一条产品原则

原文 §2.3：

1. 自主性优先
2. 少说话多行动
3. 无打字是完整主路径
4. 语音不是唯一入口
5. 游戏感来自内在反馈
6. 理解变化必须有证据
7. 一轮有终点
8. 推荐可解释可拒绝
9. 个人偏好不是人格标签
10. 失败不是身份
11. 处处可达按需介入

## 明确非目标

原文 §2.4：

1. 排行榜/好友比较/公开掌握状态/学习时长竞赛
2. XP/金币/等级/宝箱/抽卡/随机奖励/体力/内容锁
3. streak/断签惩罚/红色逾期债务/固定每日目标
4. 用完成速度/口语流利度/点击量/自信度/情绪判断理解
5. 右下角通用聊天机器人或无限陪聊
6. Agent 生成任意 HTML/JS 前台执行
7. 前台伴侣在 trusted 作答前访问隐藏答案/rubric/evidence
8. 模型自动确认概念关系/修改共享图真值/正式调度
9. 强制所有知识点用同一种小游戏
10. 用参与度/DAU/留存替代真实学习效果证明
11. 公测首版 VR/AR、实时多人协作、社交路线或开放式 Agent 自主联网
