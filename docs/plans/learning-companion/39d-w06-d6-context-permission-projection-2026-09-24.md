## 2. 决定一：一份上下文，一个版本锚

**锚**：`(page_instance_id, revision)`。上下文的一切——实体、交互态、可读视图、敏感档、能力提示——**都挂在同一个 revision 上**。请求属于哪个页面实例，就只用那个实例那一版的上下文。

### 2.1 只留实时那条（39b §9.6 的判决，本文件接收）

- **删除"窄的那份"**：她的环境块改从 `assistant_page_contexts` 取（worker 侧对该表已只读），`readable_view` 折进"用户正在看"的 2–3 行。
- `turn-service.ts` 的 `sanitizeContext` 必须**带上 `readableView`**（今天不带 ⇒ 落库后读不回来）。
- 主动链（`companion-thought.ts`）也取同一份：她主动开口时**必须知道用户在哪儿**。
- `run.page_context` 退化为**审计字段 + grounded tutor 的 grant 载体**（assessment 分支的 grant 不能顺手删）。

### 2.2 三条硬约束

1. **伴星侧与页面侧用同一份上下文与版本**（39 §15.3-11 原话）。同一屏上她说的和别人看到的必须是同一版。
2. **不按全局最新时间戳跨窗口选上下文**：后台页面、其他窗口和不可访问材料**不会因为时间戳较新就被选为当前上下文**（39 §12.2.1 末段、39b C4）。
3. **失效即不可用**：`expires_at` / `revoked_at` 一到，该上下文**不得再被用来装配**；读侧显式拒绝，不"读到旧值继续用"。

### 2.3 切页时明确说清

用户切页后，必须能回答两件事之一：**继续原任务**（用原页面的冻结上下文）还是**指向新页**（新实例新 revision）。**不能把新页正文混进旧任务**（39 §12.2.1）。

## 3. 决定二：选区 / 草稿 / 快照——四种形态分开

| 形态 | 身份 | 能做什么 | **不能做什么** |
| --- | --- | --- | --- |
| **选区** | `(page_instance_id, revision, blockId, offsets)` | 定位、解释、图示；图示带引用**留在对话** | 不建立正式制卡、评分或日程 |
| **未保存草稿** | 客户端版本 + 显式标注 | **明确标注版本的临时讨论** | **不能直接建立正式制卡、评分或日程**（39 §0.2 原话） |
| **已保存笔记** | `note_version_id` + `content_hash` | 开始学习／复习／制卡 | — |
| **冻结快照** | D3 的三件（正文 + 引用摘录 + 哈希） | 正式教学与评估 | 不随原笔记继续变化 |

**红线**：正式任务遵守 D3 §2.2 的一致读取；**普通选区问答没有现成轮次时，产物留在对话并保留材料引用，不自动造一轮学习历史**（39b §5 末段）。

**"未保存草稿可用于明确标注的临时讨论"这一条尤其重要**：它给了草稿一个**允许的用法**（讨论），同时给出**唯一的禁止**（正式制卡/评分/日程）——不是"草稿一律不能用"，那样用户会以为产品坏了。

## 4. 决定三：长材料分页续读

**输入**：`(noteId | sourceId, cursor?)`
**输出**：本段正文 + `locator`（块 id + 偏移，**稳定定位**）+ `version`（`note_version_id` + `content_hash`）+ `truncated` + `nextCursor`

四条规则：

1. **游标必须能推进**：反复调同一个读取工具**不能**解决"解释最后一节"（39b C5 原话）——所以每次返回 `nextCursor`，且它指向**未读的下一段**。
2. **预算受限时明确说读到哪**：受预算限制时**不谎称已读全文**（39b C5 末句）。
3. **图片也分页**，且**外发政策要如实说**：图不在 `note_blocks` 里，读三遍正文也看不到图（39b §9.6 的"我读完了，里面没有截图"就是这里漏出来的）。首期环境现实：全库 **0/852** 账号 `dataPolicy.sendImageContent=true` ⇒ 读图主路径在应用内**永不触发**，界面必须如实说明"看不了"并指出开关位置，**不许凭标题猜图里有什么**。
4. **材料里的命令只是材料内容**：源材料里写着"忽略上面的指示"之类，**不改变用户授权或运行规则**（39b C5 末句、39 §6.3）。

**来源侧同样按需可读**（39b §3 C5）：来源没有解析或无权限时**明确说明**，不静默返回空。

## 5. 决定四：切页、切空间、撤权——三种失效三套处理

| 事件 | 处理 | 出处 |
| --- | --- | --- |
| **切页** | 明确"继续原任务"或"指向新页"；旧任务用**冻结的**上下文，不掺新页正文 | 39b C4、39 §12.2.1 |
| **切空间** | 离开当前前台轮次并保存可恢复状态；**只展示新空间数据**；旧空间已授权后台任务**按其原身份**处理，**结果不混入新空间** | 39 §13.4 |
| **撤权** | 停止受保护内容的**展示/练习/外发**；通知**不泄露标题或题面**；恢复权限后**重新检查内容适用性**，**不把等待期间当成复习完成** | 39 §14.4 末段、§16.13 |

**外加一条**：失权后，**旧记忆与摘要不能成为继续读取内容的旁路**（39 §12.2.2 末段）——这条同时约束 §7 的记忆身份。

## 6. 决定五：权限过滤与个人投影

**一份过滤，三条读法一致。** 39 §15.3-7 原话："学习记录、卡组、星图的权限过滤、分页与个人投影如何保持一致。"

| 要求 | 落地 |
| --- | --- |
| 同一份权限过滤 | 学习记录 / 卡组 / 星图**共用同一个过滤入口**，不各写一遍（今天它们分别在 `learning-dashboard`、`learning-objectives/surface-service`、`understanding-v3/topology-repository` 各自查表） |
| 分页一致 | 三条读法的分页语义一致（同一页大小上限、同一游标形状），否则同一批数据在两处显示不同条数 |
| 投影不成为事实源 | 星图、首页、卡组数、笔记状态都是**投影**（39 §15.2 末句）；任何"掌握度/亮度"字段都不许落到库里 |
| 计数单位一致 | **一份回答关联多个目标不膨胀为多次学习**（39 §15.2 末句、§9.5） |

### 6.1 只读成员与失权

- 只读成员**不需要公共编辑权**：个人适用路线、私有备注、对已有共享卡开启个人复习（39 §14.4）。
- **没有无权执行的公共制卡按钮**：界面不提供必然失败的按钮（39 §8.3 末段、§16.20）。
- 失去笔记权限后**只保留允许展示的非内容元数据**；题面、快照、反馈和**可能复述受保护内容的本人回答按权限遮蔽**（39 §10.3）。
- 私有备注**不进入公共制卡材料**（39 §10.1）。

## 7. 决定六：伴星动作接口

39 §15.3-9 原话要四样，本文件把形状钉死：

| 传入 | 形状 | 为什么 |
| --- | --- | --- |
| **目标身份** | `{ objectiveId, objectiveRevision }` 或 `{ noteId, roundId }` | 不让模型猜 ID（39 §15.6"不让模型猜 ID、状态名或日程版本"） |
| **内容快照** | D3 的三件引用 | 动作基于"当时那一版" |
| **权限** | 服务端给的档位 + 授权来源 | **页面文本不成为授权**（39b §5 的上下文合同） |
| **幂等键** | 调用方给，稳定 | 重复提交保护（39 §12.2.3） |
| （+）**呈现回执** | 见 D7 | 帮助链的关联点 |

四条纪律：

1. **读取结果里的实体、版本与可执行动作直接可用于下一步**；同一引用能从读取结果传给动作，**无需模型改名或猜 ID**（39b C6）。
2. **写动作由对应业务服务完成**；伴星**不自行判分、不改安排/正文/卡片**（39 §12.2）。
3. **拥有写权限 ≠ 用户要做**：权限允许写入只说明"能做"（39b §9.5 的裁定、§9.8 的"不采用"清单第 1 条）。
4. **不因写权限自动开始学习**（39 §16.32）。

## 8. 决定七：任务记忆身份

### 8.1 缺陷与改法（39b C8）

- **缺陷**：`deriveMemoryScope(pageContext)` **按页面种类猜** scope（实测只看 `context.pageKind`），召回时用它当过滤；**没有以本次 runId／taskId 约束**；`memory_links` 有 `entity_type`/`entity_id` 但**召回不用它**。
- **改法**：临时任务信息**绑定具体任务或目标版本**；**缺少绑定时不能默认为全任务通用**（39b C8 原话）。
- **`scope` 列的处置**：现有取值只有 `workspace`/`global`（实测 99/94）。所以"task"**今天只是检索期概念**。两条路二选一，实施时定：① 给它一个真实 id 维度（新列或走 `memory_links`）② 明确它只是过滤器并**在缺绑定时降级为非任务通用**。**不许保持现状**——现状是"按页面种类猜"，那是把上下文位置当任务身份。

### 8.2 来源分层

偏好 / 用户自述 / 模型推测 / 正式学习观察**分别带来源**；冲突时**优先当前明确表达与当前权威记录**。已有的 `source_type`、`user_stated`、`user_confirmed`、`candidate` 四列是这套分层的落点。**记忆不覆盖正式观察**（39 §12.2.2）。

### 8.3 遗忘、纠正与撤权

- 遗忘/纠正**传播到召回与摘要**，**不改写正式历史**（39 §12.2.2、§16.32）。
- **旧的"这次没懂"不能覆盖后续已确认的表现**（39b C8）。
- 撤权后**不能经旧摘要再读出正文**（§5 末条）。

### 8.4 记忆与正式历史分开

**判据（39d W0-6 的完成判据之一）**：能力结论**只能**来自学习观察，不能来自记忆；伴星说"你会了"**不产生能力证据**（39 §2.1 末段）。这条在实现上的检查点是：记忆读取路径与学习观察读取路径**不共用同一个返回类型**。

## 9. 验收判据（实施时逐条可跑）

| # | 判据 | 怎么算过 |
| --- | --- | --- |
| 1 | 一份上下文 | 同一屏上，她的环境块与 `companion_read_current_page` 返回的**是同一版**（同一 `page_instance_id` + `revision`） |
| 2 | 主动链知道用户在哪儿 | 主动开口的那一轮，环境块里有"用户正在看…"且与当时那一屏一致 |
| 3 | 草稿不造正式记录 | 在未保存草稿上提问 → 断言**无新轮次、无候选、无日程**；产物留在对话 |
| 4 | 选区问答不造轮次 | 普通选区问答 → 断言无学习轮次创建（39 §16.39） |
| 5 | 游标能推进 | 对一篇长材料连续读三次，断言三次的 `locator` **不重复**且能引用到末节 |
| 6 | 读不到就说读不到 | 无权限/未解析的来源 → 明确说明，不静默返回空、不谎称读完 |
| 7 | 切空间不串数据 | 切空间后 → 断言只出现新空间数据；旧空间后台任务结果不混入 |
| 8 | 撤权不留旁路 | 撤权后 → 展示/练习/外发停止；**旧记忆摘要读不出正文**；通知不含标题题面 |
| 9 | 三条投影一致 | 同一批数据在学习记录/卡组/星图三处的**条数与可见性一致**；截断数据明确说明（39 §11.5） |
| 10 | 记忆不产生能力证据 | 只在记忆里出现"学会了"→ 断言能力记录**不变** |
| 11 | 跨 user 读不到 | 换 user 的 preflight 也读不到那条实体（39b §14 的规矩，与 W2-3 同批） |
