## 实施顺序

1. FDN-01：统一版本源、release-check 基础和可复现测试摘要。

3. SEC-01 enforce：逐表 RLS、受限角色、pool reuse 和双 Worker 验证。

5. 收口 AIQ、metrics/alerts、backup/restore、coverage/scan 和 release manifest。
