# Font licenses

The desktop client bundles `Noto Sans SC Variable` and `Noto Serif SC Variable`
through `@fontsource-variable/noto-sans-sc` and `@fontsource-variable/noto-serif-sc`
version `5.3.0`.

Both typefaces are distributed under the SIL Open Font License, version 1.1
(OFL-1.1). Upstream specimens and license information are available at:

- https://fonts.google.com/noto/specimen/Noto+Sans+SC
- https://fonts.google.com/noto/specimen/Noto+Serif+SC

The package metadata and source license texts remain available in the
development dependency tree; this notice travels with the renderer asset
input so the packaged client retains attribution context.
