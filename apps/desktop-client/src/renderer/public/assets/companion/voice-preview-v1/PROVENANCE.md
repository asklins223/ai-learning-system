# 音色试听录音 voice-preview-v1

设置 → 语音与伴星 里「试听」放的音频。它们是**预生成的资产**，不是用户点下去时现合成的：
挑声音天然要把同一句话反复听几遍，每听一遍都打一次上游合成接口是白花钱。

## 生成参数

- 引擎 / 模型：`qwen-audio-3.1-tts-flash`（阿里百炼 Qwen-Audio-TTS，北京地域）
- 待合成文本（所有条目同句）：你好呀，我是伴星。今天想一起学点什么？我在这儿陪你慢慢来。
- 指令控制 instruction：可爱的年轻女性声音，25 岁左右，声音甜美温柔、略带活泼，语速自然适中，适合轻松陪伴式对话
- 音频：mp3 / 22050 Hz / 单声道
- 生成日期：2026-09-22

## 过期条件

`model`、`voice` 或上面那句 `instruction` 任何一个改了，这批录音就不再代表她实际会发出的声音，
必须整批重新生成并替换本目录；文件名就是 `voice` 参数值，界面按 `tts-voice-catalog.ts` 里的
`previewAsset` 取用，缺一行会在 `tts-voice-catalog.test.ts` 里红。
