# Learning Room v1 review package

Generated by `apps/web/scripts/build-learning-room-assets.mjs`.

`manifest.json` is intentionally marked `reviewOnly: true` until the GLB, KTX2, Electron offline, budget, and visual regression gates pass. The browser prototype loads this package to validate the spatial contract and 2D fallback.

The canonical room image (`STATIC-ROOM-01`, derived from `room-empty-day-v2.png`) is also the visual backplate in the 3D prototype. The room-shell GLB remains a hidden engineering/anchor layer in this mode; visible 3D rendering is reserved for volumetric props, characters, and future interactions. This keeps the 3D view aligned with the approved 2D art direction instead of rebuilding the room mood with procedural SVG or flat placeholder materials.
